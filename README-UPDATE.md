# Зміна — оновлення адмінпанелі 2.0

Цей архів додає сучасну аналітику команди. Дизайн календаря, Firebase Auth, Firestore Rules, зарплата, каса та PWA залишаються без змін.

ЩО ДОДАНО
- Підсумкова каса, зарплата, кількість виконаних планів, премії й облік профілів за вибраний місяць.
- Окремі графіки каси й зарплати для команди та кожного працівника.
- Топ 5 працівників за касою, пошук, фільтри активності та сортування.
- Детальна картка працівника: каса, зарплата, план, премія, заповнені зміни, журнал.
- CSV-експорт місячної статистики та JSON-експорт індивідуальних записів.
- Керування призупиненням синхронізації, як у попередній адмінпанелі.

ЯК ОНОВИТИ НА GitHub (репозиторій viliesov-d/YAPPI_)
1. Для найнадійнішої сумісності завантажте з цього ZIP в GitHub файли з його кореня ТА папки public/ у ті самі шляхи.
2. Оновлюються тільки: admin.html, admin.js, admin-metrics.js, styles.css, sw.js, version.json. У папці public/ — ті самі файли.
3. Збережіть свій firebase-config.js без змін. Не чіпайте firestore.rules, Auth, облікові записи чи приватний JSON-ключ.
4. Зробіть Commit у main і переконайтеся, що GitHub Pages завершив публікацію.
5. Відкрийте /YAPPI_/admin.html, увійдіть своїм акаунтом із правом admin=true і натисніть «Оновити дані».
6. Для встановленого PWA відкрийте з інтернетом, щоб отримати нову версію. Якщо з'явиться пропозиція оновитися — прийміть її після синхронізації записів.

Джерело даних: чинна колекція users/{uid}/data/calendar у Cloud Firestore.
Підсумкові цифри не включають акаунти, записи яких не вдалося завантажити. В інтерфейсі відображається попередження про неповні підсумки.
Під час відкриття адмінпанелі завантажується календар кожного профілю (до 4 одночасних читань). Для дуже великих команд бажано окремо оптимізувати агреговану статистику в бекенді.

Безпека: перевірка ролі admin=true (Custom Claims) і Firestore Rules зберігається. Призупинення синхронізації не відключає Firebase Authentication.

Після оновлення не потрібно повторно реєструвати адміністратора або налаштовувати Firebase.
